# 学霸帝AI - 本地多模态AI助手

基于 MNN-LLM 引擎的 Android 本地 AI 助手应用。

## 功能特点

- 🖼️ **图像理解** - 上传图片进行对话
- 🤔 **深度思考** - 思维链推理
- 🔊 **语音输入** - 支持语音对话（需下载 ASR 模型）
- 🔒 **完全本地** - 无需网络，隐私安全

## 首次使用

1. 下载安装 APK
2. 打开应用，下载推荐模型（约 1.4GB）
3. 开始对话

## 模型信息

默认模型：`Qwen3-VL-2B-Thinking-MNN`
- 多模态视觉理解 + 深度思考
- 中英双语支持
- 完全本地推理

## 技术架构

- 基于 MNN（Mobile Neural Network）推理引擎
- 支持 CPU / OpenCL 后端
- 阿里巴巴 Qwen 系列模型
